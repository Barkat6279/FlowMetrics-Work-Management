# Security policy

This repository is an educational/demo MVP, not a production-ready service. Do not deploy it with real employee records or real credentials.

The demo implementation uses simple demo credentials and in-memory bearer tokens. Before production use, replace this with password hashing, durable/revocable sessions, rate limiting, CSRF/CORS policy appropriate to the deployment, audit logging, input limits, backups, and a security review.

Please do not publish exploit details or real personal data in public issues.
